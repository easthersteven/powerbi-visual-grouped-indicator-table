## Response times

Support is provided in English, free of charge, on a best-effort basis.
Acknowledgement of a new issue is typically within **2 business days**.
There is no paid support tier and no contractual SLA.

## Before you report a problem

Please check the [README](https://github.com/easthersteven/powerbi-visual-grouped-indicator-table#readme) for the field bindings and formatting options, and
search [existing issues](https://github.com/easthersteven/powerbi-visual-grouped-indicator-table/issues?q=is%3Aissue) in case the problem is already known.

## What to include in a report

1. The visual name and version (Format pane → **About**, or the version in the
   `.pbiviz` file name).
2. Where it happens: Power BI Desktop (and its version) or the Power BI service, plus the
   browser if in the service.
3. What you did, what you expected, and what happened instead.
4. A screenshot of the visual and of the Fields/Format pane settings involved.
5. If possible, a small sample .pbix that reproduces the problem using non-confidential
   data. **Do not send confidential or personal data** — see the
   [privacy policy](https://github.com/easthersteven/powerbi-visual-grouped-indicator-table/blob/main/PRIVACY.md).

## Scope

Supported: defects in the visual, questions about its data roles and formatting options,
and compatibility problems with current versions of Power BI Desktop and the Power BI
service.

Out of scope: authoring your report or data model, DAX and Power Query help, Power BI
licensing and tenant administration, and problems reproducible with Microsoft's built-in
visuals. Those are best raised with the
[Microsoft Power BI Community](https://community.fabric.microsoft.com/) or Microsoft
support.

## Supported versions

The current release is supported. Fixes are shipped as new versions through AppSource;
older versions are not patched, so please update before reporting an issue.

## Security

Do not open a public issue for a suspected security problem. Email
<easthersteven@gmail.com> with the details and allow time for a fix before disclosing.
