# Privacy Policy — Grouped Indicator Table

**Publisher:** Steve Easther
**Product:** Grouped Indicator Table, a Power BI custom visual
**Last updated:** 24 August 2026

## Summary

Grouped Indicator Table does not collect, store, share, or transmit any personal data. It has no
back end, no accounts, and no analytics.

## What data the visual handles

The visual receives only the data you bind to it in your Power BI report (the fields
placed in its data roles) plus the formatting options you set in the Format pane. That
data is processed in memory inside the Power BI rendering sandbox, in your browser or in
Power BI Desktop, solely to draw the visual. It is discarded when the visual is redrawn or
the report is closed.

Formatting options you configure are saved by Power BI inside your own report file
(.pbix) or workspace, under your control. The publisher has no access to them.

## What the visual does not do

- It does not send data to the publisher or to any third party.
- It makes no network requests. It declares no privileges (`"privileges": []` in
  `capabilities.json`), so it has no access to external services, local storage, the
  clipboard, or the file system.
- It uses no cookies, no tracking technologies, and no telemetry or usage analytics.
- It does not use advertising or profiling of any kind.
- It contains no third-party runtime services; it is built only on the Microsoft
  Power BI visuals API.

## Your data stays with Microsoft

Because the visual never transmits anything, the handling of the data displayed in your
report is governed by your own organisation's policies and by the
[Microsoft Privacy Statement](https://privacy.microsoft.com/privacystatement) for the
Power BI service.

## Support requests

If you contact the publisher for support, the publisher will receive only what you choose
to include in that message (for example your email address and any screenshots or sample
files you attach). Please do not send confidential or personal data. See
[SUPPORT.md](https://github.com/easthersteven/powerbi-visual-grouped-indicator-table/blob/main/SUPPORT.md).

## Changes to this policy

Any change to this policy will be published on this page with an updated date above.
